# CareerForge 鑄途 — careerforgehk.com

香港身份與職涯發展一站式規劃系統。

## Live site
- Production: https://careerforgehk.com
- Netlify site: vocal-pothos-4360e4

## Stack
- Pure static HTML / CSS / JS
- No build step
- Trilingual (繁體 / 简体 / EN)

## Files
- `index.html`, `index-cn.html`, `index-en.html` — landing pages
- `career.html*`, `education.html*`, `visa.html*`, `quiz.html*`, `cases.html*` — content pages (each language variant)
- `assets/`, `css/`, `js/` — shared resources

## Deploy
Auto-deploy via Netlify on push to `main`. No manual steps needed.
